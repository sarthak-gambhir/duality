# Duality

A strict **two-color** design system for React + TypeScript. Everything is drawn with exactly two themeable colors — `--fg` (foreground) and `--bg` (background). There are no intermediate shades, no hue variants, and no transparency. Depth and state are expressed through **inversion**, **pixel / dither patterns**, and **border-style changes** — never by color alone.

## About this project

Duality is an opinionated design system built on the constraint of exactly two colors. By removing the freedom to add a third color, we're forced to be intentional about every visual decision. State changes, hierarchy, and contrast must be expressed through geometry and texture instead of hue. The result is a system that's simultaneously minimal, accessible, and composable.

This Storybook documents all components, foundations, and patterns. Visit the [live Storybook](https://duality-storybook.onrender.com) hosted on Render.

## Install

```bash
pnpm add @astrabound/duality
```

## Usage

Wrap your app in a `ThemeProvider` and import the stylesheet once:

```tsx
import { ThemeProvider, Button } from "@astrabound/duality";
import "@astrabound/duality/styles.css";

export function App() {
  return (
    <ThemeProvider defaultTheme="classic">
      <Button>Get started</Button>
    </ThemeProvider>
  );
}
```

Use the **Theme** control in the toolbar (top of the canvas) to preview any story under a different two-color theme.

## Principles

- **Two colors only.** Every surface resolves to `--fg` on `--bg`, or the inverse. See _Foundations → Two-Color Model_.
- **State without color.** Hover / selected inverts the pair, focus adds an outline, and disabled uses a texture fill (dither or hatch) that keeps its text legible - an outlined label on selection controls, or a readable value plate on value controls.
- **AAA contrast.** Every palette meets WCAG AAA (7:1) between the two colors.
- **Accessible by default.** Interactive components ship with the correct ARIA roles, keyboard support, and focus management.

## Categories

- **Foundations** — the two-color model and palettes.
- **Layout** — `Box`, `Stack`, `Inline`, `Grid`, `Container`, `Divider`.
- **Typography** — `Text`, `Heading`, `Link`, `Code`, `Kbd`.
- **Controls** — form inputs: `Button`, `Input`, `Select`, `Combobox`, `Slider`, `RangeSlider`, `DatePicker`, and more.
- **Forms** — `FormField` composition.
- **Display** — `Card`, `Badge`, `Alert`, `Avatar`, `Progress`, `Spinner`, `Skeleton`.
- **Data** — `Table`, `Tree`.
- **Navigation** — `Breadcrumbs`, `Pagination`.
- **Disclosure** — `Tabs`, `Accordion`.
- **Overlays** — `Modal`, `Tooltip`, `Popover`, `Menu`, `Toast`.
- **Theming** — `PaletteSelect`.
- **Guides** — accessibility, theming & density, and two-color patterns.
- **Examples** — full composed demo pages (Dashboard, Settings, Email, File Manager, Checkout, Command Center) showing many components working together.
