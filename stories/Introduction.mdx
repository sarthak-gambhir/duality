# Duality

A strict **two-color** design system for React + TypeScript. Everything is
drawn with exactly two themeable colors — `--fg` (foreground) and `--bg`
(background). There are no intermediate shades, no hue variants, and no
transparency. Depth and state are expressed through **inversion**, **pixel /
dither patterns**, and **border-style changes** — never by color alone.

## Install

```bash
pnpm add @duality/ui
```

## Usage

Wrap your app in a `ThemeProvider` and import the stylesheet once:

```tsx
import { ThemeProvider, Button } from "@duality/ui";
import "@duality/ui/styles.css";

export function App() {
  return (
    <ThemeProvider defaultTheme="classic">
      <Button>Get started</Button>
    </ThemeProvider>
  );
}
```

Use the **Palette** and **Invert** controls in the toolbar (top of the canvas)
to preview any story under a different two-color palette.

## Principles

- **Two colors only.** Every surface resolves to `--fg` on `--bg`, or the
  inverse. See _Foundations → Two-Color Model_.
- **State without color.** Hover / selected inverts the pair, focus adds an
  outline, and disabled uses a dither fill with an outlined label so text stays
  legible.
- **AAA contrast.** Every palette meets WCAG AAA (7:1) between the two colors.
- **Accessible by default.** Interactive components ship with the correct ARIA
  roles, keyboard support, and focus management.

## Categories

- **Foundations** — the two-color model and palettes.
- **Layout** — `Box`, `Stack`, `Inline`, `Grid`, `Container`, `Divider`.
- **Typography** — `Text`, `Heading`, `Link`, `Code`, `Kbd`.
- **Controls** — form inputs: `Button`, `Input`, `Select`, `Combobox`,
  `Slider`, `RangeSlider`, `DatePicker`, and more.
- **Forms** — `FormField` composition.
- **Display** — `Card`, `Badge`, `Alert`, `Avatar`, `Progress`, `Spinner`,
  `Skeleton`.
- **Data** — `Table`, `Tree`.
- **Navigation** — `Breadcrumbs`, `Pagination`.
- **Disclosure** — `Tabs`, `Accordion`.
- **Overlays** — `Modal`, `Tooltip`, `Popover`, `Menu`, `Toast`.
- **Theming** — `ThemeToggle`, `PaletteSelect`.
