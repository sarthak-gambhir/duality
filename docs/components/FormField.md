# FormField

Composes a label, optional hint, and error around a single control, wiring `id`, `aria-describedby`, `aria-invalid`/`aria-errormessage`, `aria-required`, and `disabled` for accessibility. Works with a render prop (custom controls) or with plain children via {@link FormFieldContext}.

## Props

| Prop                  | Type                                                         | Default | Description                                                                                                                                                                                                 |
| --------------------- | ------------------------------------------------------------ | ------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `children` (required) | `ReactNode \| ((props: FormFieldControlProps) => ReactNode)` | -       | Render the control, spreading the provided a11y props onto it. Optional: when omitted, children are rendered directly and controls that consume {@link useFormField } pick up the same wiring from context. |
| `className`           | `string`                                                     | -       |                                                                                                                                                                                                             |
| `disabled`            | `boolean`                                                    | -       | Disable the field: dims the label and forwards `disabled` to the control.                                                                                                                                   |
| `disabledReason`      | `ReactNode`                                                  | -       | When the field is disabled, the reason shown in a persistent caption below the control.                                                                                                                     |
| `error`               | `ReactNode`                                                  | -       | Error message; when set, the control is marked invalid.                                                                                                                                                     |
| `hint`                | `ReactNode`                                                  | -       | Optional helper text shown below the label.                                                                                                                                                                 |
| `id`                  | `string`                                                     | -       | Override the generated control id.                                                                                                                                                                          |
| `label` (required)    | `ReactNode`                                                  | -       | Field label text.                                                                                                                                                                                           |
| `required`            | `boolean`                                                    | -       | Marks the field required (visual marker + `aria-required` on the control).                                                                                                                                  |
