# TextureSelect

A Select bound to the current texture fill (dither or hatch).

## Props

| Prop         | Type               | Default   | Description                                              |
| ------------ | ------------------ | --------- | -------------------------------------------------------- |
| `align`      | `"end" \| "start"` | `start`   | Which edge the dropdown anchors to. Defaults to "start". |
| `aria-label` | `string`           | `Texture` | Accessible label. Defaults to "Texture".                 |
| `className`  | `string`           | -         |                                                          |
