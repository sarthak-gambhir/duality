# Link

Text link: underlined by default, inverts on hover.

## Props

| Prop        | Type                            | Default  | Description                                                                                                                            |
| ----------- | ------------------------------- | -------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `external`  | `boolean`                       | -        | Treat as an external link: opens in a new tab with a safe `rel` and a trailing external-link glyph. Explicit `target`/`rel` still win. |
| `underline` | `"none" \| "always" \| "hover"` | `always` | Underline policy. Defaults to `"always"`.                                                                                              |
