# DensitySelect

A Select bound to the current spacing/sizing density.

## Props

| Prop         | Type               | Default   | Description                                              |
| ------------ | ------------------ | --------- | -------------------------------------------------------- |
| `align`      | `"end" \| "start"` | `start`   | Which edge the dropdown anchors to. Defaults to "start". |
| `aria-label` | `string`           | `Density` | Accessible label. Defaults to "Density".                 |
| `className`  | `string`           | -         |                                                          |
