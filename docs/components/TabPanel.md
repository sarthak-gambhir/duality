# TabPanel

Content panel shown when its tab is selected.

## Props

| Prop               | Type      | Default | Description                                                          |
| ------------------ | --------- | ------- | -------------------------------------------------------------------- |
| `keepMounted`      | `boolean` | -       | Keep the panel mounted (hidden) when inactive instead of unmounting. |
| `value` (required) | `string`  | -       | Value of the tab this panel belongs to.                              |
