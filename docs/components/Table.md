# Table

Two-color data table with pixel rules. Use with the T* section primitives.

## Props

| Prop           | Type                   | Default | Description                                                    |
| -------------- | ---------------------- | ------- | -------------------------------------------------------------- |
| `size`         | `"sm" \| "md" \| "lg"` | `md`    | Cell padding scale. Defaults to `md`.                          |
| `stickyHeader` | `boolean`              | -       | Pin the header row while the table's scroll container scrolls. |
