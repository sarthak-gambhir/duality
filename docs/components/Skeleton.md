# Skeleton

Dithered placeholder block for loading states.

## Props

| Prop     | Type               | Default | Description                                    |
| -------- | ------------------ | ------- | ---------------------------------------------- |
| `height` | `string \| number` | `16`    | Height (number = px). Defaults to a text line. |
| `width`  | `string \| number` | `100%`  | Width (number = px).                           |
