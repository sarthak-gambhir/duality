# AccordionItem

A single collapsible section within an Accordion.

## Props

| Prop               | Type        | Default | Description                                         |
| ------------------ | ----------- | ------- | --------------------------------------------------- |
| `disabled`         | `boolean`   | -       | Disable opening/closing and focus for this section. |
| `title` (required) | `ReactNode` | -       | Header content.                                     |
| `value` (required) | `string`    | -       | Unique value identifying this section.              |
