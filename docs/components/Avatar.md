# Avatar

Square, pixel-framed avatar showing an image or derived initials.

## Props

| Prop   | Type                           | Default | Description                                          |
| ------ | ------------------------------ | ------- | ---------------------------------------------------- |
| `alt`  | `string`                       | -       | Image alt text (defaults to `name`).                 |
| `name` | `string`                       | -       | Name used to derive initials when no image is given. |
| `size` | `"xs" \| "sm" \| "md" \| "lg"` | `md`    | Size.                                                |
| `src`  | `string`                       | -       | Image source.                                        |
