# Checkbox

Two-color checkbox with a native input and a drawn pixel mark.

## Props

| Prop            | Type        | Default | Description                              |
| --------------- | ----------- | ------- | ---------------------------------------- |
| `indeterminate` | `boolean`   | `false` | Renders the mixed (indeterminate) state. |
| `label`         | `ReactNode` | -       | Text shown next to the box.              |
