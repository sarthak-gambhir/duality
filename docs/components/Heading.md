# Heading

Section heading on a stepped scale. `visualLevel` styles without changing the tag.

## Props

| Prop          | Type                         | Default | Description                                                       |
| ------------- | ---------------------------- | ------- | ----------------------------------------------------------------- |
| `level`       | `1 \| 2 \| 3 \| 4 \| 5 \| 6` | `2`     | Semantic heading level, 1-6. Sets the rendered `h1`-`h6` element. |
| `visualLevel` | `1 \| 2 \| 3 \| 4 \| 5 \| 6` | -       | Visual size, decoupled from the tag. Defaults to `level`.         |
