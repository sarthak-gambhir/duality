# EmptyState

Centered placeholder for empty lists, searches, or first-run screens.

## Props

| Prop               | Type        | Default | Description                                       |
| ------------------ | ----------- | ------- | ------------------------------------------------- |
| `action`           | `ReactNode` | -       | Action slot (e.g. a Button) shown below the text. |
| `className`        | `string`    | -       |                                                   |
| `description`      | `ReactNode` | -       | Supporting explanation.                           |
| `icon`             | `ReactNode` | -       | Optional visual/marker above the title.           |
| `title` (required) | `ReactNode` | -       | Primary heading.                                  |
