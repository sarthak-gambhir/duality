# AvatarGroup

Overlapping stack of `Avatar`s with an optional `+N` surplus chip.

## Props

| Prop   | Type                           | Default | Description                                                          |
| ------ | ------------------------------ | ------- | -------------------------------------------------------------------- |
| `max`  | `number`                       | -       | Maximum avatars to show before collapsing the rest into a `+N` chip. |
| `size` | `"xs" \| "sm" \| "md" \| "lg"` | `md`    | Size applied to the surplus chip (match the avatars you pass in).    |
