# Spinner

Stepped pixel-rotation loading indicator.

## Props

| Prop    | Type                   | Default   | Description                                      |
| ------- | ---------------------- | --------- | ------------------------------------------------ |
| `label` | `string`               | `Loading` | Accessible loading label. Defaults to "Loading". |
| `size`  | `"sm" \| "md" \| "lg"` | `md`      | Size.                                            |
