# Label

Form label; associate with a control via `htmlFor`.

## Props

| Prop       | Type      | Default | Description                                                      |
| ---------- | --------- | ------- | ---------------------------------------------------------------- |
| `disabled` | `boolean` | -       | Dim the label to reflect a disabled control (styling hook only). |
| `required` | `boolean` | -       | Shows a required marker after the text.                          |
