# IconsProvider

Globally re-skin Duality's semantic icons by supplying overrides.

## Props

| Prop               | Type                    | Default | Description                                                     |
| ------------------ | ----------------------- | ------- | --------------------------------------------------------------- |
| `icons` (required) | `Partial<DualityIcons>` | -       | Partial overrides merged over the built-in Remix fill icon set. |
