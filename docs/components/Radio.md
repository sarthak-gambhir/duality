# Radio

Two-color radio. Inside a RadioGroup it wires name/checked/onChange.

## Props

| Prop    | Type        | Default | Description                                        |
| ------- | ----------- | ------- | -------------------------------------------------- |
| `label` | `ReactNode` | -       | Text shown next to the indicator.                  |
| `value` | `string`    | -       | This option's value. Required within a RadioGroup. |
